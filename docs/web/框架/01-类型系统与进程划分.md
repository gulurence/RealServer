# 类型系统与进程划分

> RealServer 的「类型系统」由三类枚举构成，各自职责分离、值域重叠但靠前缀区分：
>
> | 枚举 | 前缀 | 定义处 | 语义 |
> |---|---|---|---|
> | `EProcessType` | `P` | `engine/xCluster/xProcessDefine.h` | 进程类型（部署容器），决定本进程可承载哪些 Actor |
> | `EActorType` | `A` | `engine/xCluster/xProcessDefine.h` | Actor 类型（进程内动态负载单元） |
> | `ActorType`（proto） | `AT_` | `source/proto-def/msg/msg_id.proto` | 协议路由枚举（`big_type` 字段取值） |

## 1. 进程枚举清单 `EProcessType`

| 值 | 名称 | 说明 |
|---|---|---|
| 0 | `EProcessType_None` | 未指定 |
| 100 | `EProcessType_PGate` | 网关进程（客户端接入） |
| 101 | `EProcessType_PLogin` | 登录进程 |
| 102 | `EProcessType_PGlobal` | **全局进程**（承载 Friend/Room/Chat/Spectator） |
| 201 | `EProcessType_PGame` | 游戏进程（承载 Player/World/Battle） |
| 202 | `EProcessType_PWorld` | 世界进程（备用，World 作为 Actor 由 Game 承载） |
| 末尾 | `EProcessType_Max` | 哨兵 |

## 2. Actor 枚举清单 `EActorType`

| 值 | 名称 | 承载进程 | 实例性 | 脚本目录 |
|---|---|---|---|---|
| 0 | `EActorType_None` | — | — | — |
| 100 | `EActorType_AGate` | Gate | 单例 | `gate` |
| 101 | `EActorType_ALogin` | Login | 单例 | `login` |
| 102 | `EActorType_AFriend` | Global | 单例 | `friend` |
| 103 | `EActorType_ARoom` | Global | 单例 | `room` |
| 104 | `EActorType_AChat` | Global | 单例 | `chat` |
| 201 | `EActorType_APlayer` | Game | 多实例 | `player` |
| 202 | `EActorType_AWorld` | Game | 单例 | `world` |
| 203 | `EActorType_ABattle` | Game | 多实例 | `battle` |
| 204 | `EActorType_ASpectator` | Global | 多实例 | `spectator` |
| 末尾 | `EActorType_Max` | — | — | — |

## 3. 端口表 `GetBasePortForType`

每类型预留 50 个端口区间，同机多实例递增分配：

| 进程类型 | 基础端口 | 区间 |
|---|---|---|
| Gate | 50551 | 50551-50600 |
| Login | 50601 | 50601-50650 |
| Game | 50651 | 50651-50700 |
| World | 50701 | 50701-50750 |
| **Global** | **50751** | **50751-50800** |

> 注：原 50051-50250 段与 Windows Docker/Hyper-V/WSL 保留端口（50000-50366）重叠，故整体上移。

## 4. `GetHostedActorTypes` 映射表（进程 → 承载 Actor）

| 进程类型 | 承载的 Actor 类型 |
|---|---|
| `PGate` | `AGate` |
| `PLogin` | `ALogin` |
| `PGlobal` | `AFriend`、`ARoom`、`AChat`、`ASpectator` |
| `PGame` | `APlayer`、`AWorld`、`ABattle` |
| `PWorld` | `AWorld` |

反向映射 `ActorTypeToProcessType`：`AFriend/ARoom/AChat/ASpectator → PGlobal`，`APlayer/AWorld/ABattle → PGame`。

## 5. 与 proto `AT_` 枚举的对应关系

`source/proto-def/msg/msg_id.proto` 的 `ActorType` 枚举（`AT_` 前缀）是协议 `big_type` 路由字段，与业务 Actor 一一对应：

| proto `AT_` | 值 | 对应 C++ `EActorType` |
|---|---|---|
| `AT_NONE` | 0 | `EActorType_None` |
| `AT_GATE` | 100 | `EActorType_AGate` |
| `AT_LOGIN` | 101 | `EActorType_ALogin` |
| `AT_FRIEND` | 102 | `EActorType_AFriend` |
| `AT_ROOM` | 103 | `EActorType_ARoom` |
| `AT_CHAT` | 104 | `EActorType_AChat` |
| `AT_PLAYER` | 201 | `EActorType_APlayer` |
| `AT_WORLD` | 202 | `EActorType_AWorld` |
| `AT_BATTLE` | 203 | `EActorType_ABattle` |
| `AT_SPECTATOR` | 204 | `EActorType_ASpectator` |

> 注意：改了 `msg_id.proto` 后需跑 `source/proto-def/make.bat` 重新生成 `source/proto-cpp/protocol/msg/msg_id.pb.*`（本阶段不跑，避免生成物与并行改动冲突）。
