# 登录模块（LoginActor）

> 里程碑 M1 · 进程类型 `EProcessType_PLogin=101` · Actor 类型 `EActorType_ALogin=101`

## 定位

登录是登录链路的唯一入口，单例 Actor（`id=0`），常驻 Login 进程。客户端经 Gate 建立 TCP 连接后，登录请求由 Gate 通过 `RPC_METHOD_LOGIN` 转发到本 Actor 的 `on_rpc_login`，返回客户端回包 protobuf。

## 消息 ID（`login.proto`）

| 常量 | 值 | 方向 |
|------|----|------|
| `LOGIN_REQ` | 1 | 客户端 → 服务器 |
| `LOGIN_RSP` | 2 | 服务器 → 客户端 |
| `SELECT_ROLE_REQ` | 3 | 客户端 → 服务器 |
| `SELECT_ROLE_RSP` | 4 | 服务器 → 客户端 |

RPC 层用 1 字节 op 区分两条链路：`LOGIN=1`（登录校验）、`SELECT_ROLE=2`（选角）。

## 错误码

| 常量 | 值 |
|------|----|
| `NONE` | 0 |
| `SESSION_INVALID` | 1001 |
| `ACCOUNT_NOT_FOUND` | 1002 |
| `ROLE_NOT_FOUND` | 1003 |
| `NO_AVAILABLE_PROCESS` | 1004 |

## 关键流程

1. **登录** `rpc_login`：`si_pb_login_req_token` 取 token → `Session.validate` 校验 → `Account.setState(LOGGED_IN → ROLE_LISTED)` → 回 `LoginRsp`。
2. **选角** `rpc_select_role`：`Account.setState(ROLE_SELECTED)` → `ActorCreator.balanceCreate(AT.PLAYER, roleId)` 挑最低负载 Game 进程创建 PlayerActor → `Account.setState(IN_GAME)` → 回 `SelectRoleRsp`。
