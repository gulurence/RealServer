================================================================================
                        luacore API Reference
             C++ → Lua bridge (SWIG-generated bindings)
================================================================================

All functions/types below are accessed via the global `luacore` table,
registered at startup by LuaVM::InitLuacoreModule().

Version: Lua 5.4.7  |  SWIG 4.3  |  RealServer Engine
================================================================================


1. TYPE CONVERSION HELPERS
================================================================================

  Lua 5.4 numeric literals (e.g. 100) are floats by default. SWIG wrappers
  expect integer subtype. Use these to explicitly cast before C++ calls.

    luacore.toint32(n)          -- Cast Lua number → int32  (ActorType, etc.)
    luacore.toint64(n)          -- Cast Lua number → int64  (ActorID, etc.)

  Usage:
    luacore.si_actor_mgr_add_hosted_type(luacore.toint32(actorType))


2. LOGGING
================================================================================

    luacore.si_log_trace(msg)   -- XTRC  trace
    luacore.si_log_debug(msg)   -- XDBG  debug
    luacore.si_log_info(msg)    -- XLOG  info
    luacore.si_log_warn(msg)    -- XWRN  warning
    luacore.si_log_error(msg)   -- XERR  error

  All messages are prefixed with "[Lua]" in the log output.
  Wrapped by xEngine.Log (common/util/log.lua).

    luacore.xTime.getHour(time)         → int     Hour

7. SYNCHRONIZATION
================================================================================

    cs = luacore.CCriticalSection()         -- Critical section
    cs:Lock() / cs:Unlock()

    mtx = luacore.CMutexLock()              -- Mutex
    mtx:Lock() / mtx:Unlock()
    mtx = luacore.CMutexLock.CreateNew(name, existTest)  -- Named/static

    lock = luacore.CSingleLock(pLock)       -- RAII scoped lock
    -- auto-locks on construction, auto-unlocks on destruction


8. ACTOR — CORE BRIDGE
================================================================================

  -- CActor class (luacore.CActor)
  -- %feature("director") enables Lua subclassing; C++ calls are forwarded
  -- to Lua overrides.

    actor = luacore.CActor(type, id, name)  → CActor

  -- Instance methods:
    actor:GetActorType()        → int32     actor:SetCreateEnable(bool)
    actor:GetActorID()          → int64     actor:CreateIsEnable() → bool
    actor:GetActorName()        → string    actor:GetLoadScore() → int32
    actor:SetLoadScore(v)                   actor:GetCreateTime() → int64
    actor:SetCreateTime(v)                  actor:GetState() → int32
    actor:SetState(v)                       actor:GetOwnerID() → int64
    actor:SetOwnerID(v)

  -- Pure virtual (override in Lua subclass):
    actor:Init()                → bool      Called once at creation
    actor:Install()             → bool      Install environment/services
    actor:UnInstall()           → bool      Teardown
    actor:Create(newID)         → CActor*   Clone/factory

  -- ActorCreator (static wrappers, luacore.ActorCreator.*)
    ActorCreator.RegistActor(actor)         → bool    Register prototype
    ActorCreator.CreateActor(type, id)      → CActor* Create from prototype
    ActorCreator.SetCreateEnableProxy(t, b) → void    Enable/disable type

  -- ActorPtr accessors (luacore.si_get_* / si_set_*)
    luacore.si_get_type(actor)              → int32
    luacore.si_get_id(actor)                → int64
    luacore.si_get_load_score(actor)        → int32
    luacore.si_get_create_time(actor)       → int64
    luacore.si_get_state(actor)             → int32
    luacore.si_get_owner_id(actor)          → int64
    luacore.si_set_load_score(actor, v)
    luacore.si_set_create_time(actor, v)
    luacore.si_set_state(actor, v)
    luacore.si_set_owner_id(actor, v)

  -- Actor lifecycle (luacore.si_actor_*)
    luacore.si_actor_regist(type, actor)            → bool
    luacore.si_actor_create(type, id)               → ActorPtr
    luacore.si_lua_actor_create(type, id, name)     → ActorPtr
    luacore.si_actor_dispatch_rpc(ptr, rpc, data)   → bool

11. REDIS (Synchronous)
================================================================================

  Uses pool "actor_cache". Blocking calls.

    luacore.si_redis_get(key)           → string  Value, or "" on miss
    luacore.si_redis_set(key, value)    → bool    True on success
    luacore.si_redis_del(key)           → bool    True on success


12. DATABASE (Async)
================================================================================

  Operations are queued via COperatorMgr; results arrive via DB callback
  (not directly visible to Lua). Table schema: (id BIGINT, data BLOB).

    luacore.si_db_select(table, where)          → string (empty)
    luacore.si_db_insert(table, data)           → bool
    luacore.si_db_update(table, data, where)    → int32 (always 0)
    luacore.si_db_delete(table, where)          → int32 (always 0)


13. RECORD NOTIFICATION
================================================================================

    luacore.si_record_notify(type, id, saveType)   → bool
      saveType: 1=insert, 2=update, 3=delete
